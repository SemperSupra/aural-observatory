# R9-P — macOS/Linux installable desktop launcher candidates

- **Windows**: existing user-scoped NSIS setup EXE, desktop/start menu shortcut and uninstall; public Windows runner tests actual installed UI startup/exit and install/repeat/uninstall.
- **macOS ARM64**: unsigned/unnotarized `AuralObservatory.app` bundle candidate containing the same published C# binary and a minimal launch script. `Info.plist` lint and executable presence are automated. Finder startup, Gatekeeper behavior, signing/notarization and accessibility with Safari/VoiceOver remain unqualified; do not represent this as a production installer.
- **Linux x64**: portable self-contained archive with opt-in no-root `install-user.sh` and `uninstall-user.sh`; writes binary under `~/.local/opt/aural-observatory` and freedesktop shortcut under `${XDG_DATA_HOME:-~/.local/share}/applications`, themed `audio-headphones` icon, default browser host. Public Ubuntu runner performs synthetic per-user install and uninstall, verifying data directories are not touched. Flatpak/deb/rpm and actual Orca/desktop-shell test remain future targets.
- **Single shared app**: platform wrappers launch `AuralObservatory.SearchDesktop`; no platform-specific DSP fork or separate codebase. User settings and experiment data in OS user-data directories outside installed executable.
- **Scope**: source-controlled candidate package recipes, no signing keys, installation into user account only when explicitly invoked, no store publish, no real health/biometric data in CI. 
- **DLE release gate**: candidate artifacts are not general releases. Actual OS launch, app lifetime, upgrade/rollback, real hearing-aid/headphone response and assistive access must be independently tested. Foundry private admission remains HOLD.
